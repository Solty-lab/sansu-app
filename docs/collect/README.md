# 声を Google スプレッドシートに自動で集める

アプリ (娘さんのページ・保護者ページ・お試し) で押された声と保護者のメモを、保護者の Google スプレッドシートに自動で送ります。
「わかった」(説明が分かった) は数が多いので送りません。

## 保護者の設定 (1回だけ、パソコン推奨)
1. Google ドライブで新しいスプレッドシートを作る (名前は自由)
2. メニュー「拡張機能」→「Apps Script」
3. 最初からあるコードを全部消して、[apps-script.gs](apps-script.gs) の中身を貼り付けて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、次のユーザーとして実行「自分」、アクセスできるユーザー「全員」→「デプロイ」→ アクセスを承認
5. 表示された「ウェブアプリ URL」(…/exec で終わる) と、スプレッドシートの URL をプロジェクトのスレッドに貼る

## Claude の作業
- `src/ui.js` の `COLLECT_URL` にウェブアプリ URL を入れてビルド・公開する
- 収集: スプレッドシートの「声」シートで「対応」列が空の行を読み、対応したら「対応」列に版や FB 番号を書く

## 注意
- アプリのコードは公開されているので、URL を知っていれば誰でも行を「追加」できます (読むことはできません)。おかしな行があれば無視します。
- 送れなかった分は端末にためておき、次に開いたとき・オンラインに戻ったときに送り直します。
